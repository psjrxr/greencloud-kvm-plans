## 适合谁，不适合谁

**适合：**

- 预算极紧、跑纯海外业务的用户。年付 25 美元以内拿到 EPYC + 10Gbps + 2–4TB 流量，这个配置价格比很难找到对手。
- 需要“多开”的用户。手里有几个小项目要分散部署，每台年付 15–25 美元的成本压力很低。
- 挂监控节点、爬虫出口、个人 Git 服务这类“低价值高可用”需求的用户。

**不太适合：**

- 主要需求是回国线路的用户。社区讨论里反复提到：绿云亚洲机房（东京 IIJ/Softbank 线）白天延迟不错，但晚高峰丢包率偏高，均非运营商深度优化回程；香港、越南机房的流量配额还只有欧美同价位的零头。要稳定回国体验，这个需求段有专门做中国优化线路的商家（年付 169.99 美元起步），预算差着一个量级。
- 需要 Windows 系统的用户。这条线仅支持 Linux。
- 需要“先试后买”退款保障的用户。

## 按场景选套餐的决策规则

把前面的信息收拢成几条可执行的规则：

1. **只跑一个轻量服务** → -1 档任意有货机房，年付 15 美元，优先 EPYC + NVMe 的。
2. **多个服务、需要 4GB 内存** → -2 档；有货机房里优先 NVMe 的（如凤凰城），其次选含 SWAP 的达拉斯。
3. **吃内存的场景（数据库、容器组）** → -3 档，优先看达拉斯（8GB + 4GB SWAP）和芝加哥。
4. **必须 NVMe 但热门机房售罄** → 要么接受 E5v4 + SSD 的在售机房，要么等下一轮补货；没有固定补货时间表。
5. **对 IPv6 有要求** → 避开堪萨斯城和香港 DC2（/112），选其他 /64 机房。
6. **要在亚洲机房用** → 注意 750GB 流量上限，流量大户选欧美机房。
7. **预算 200 美元/年以上且看重回国质量** → 这条产品线不是你的答案，看更贵的产品类别或换商家。
